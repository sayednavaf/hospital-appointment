
# Hospital Appointment Booking System
![Build](https://github.com/sayednavaf/hospital-appointment/actions/workflows/maven.yml/badge.svg)

A web application for booking and managing doctor appointments, built with Spring Boot.

## Features
- Patient and doctor registration and login
- Browse doctors and book appointments
- Doctors can view their appointments and patient lists
- Cancel or delete appointments

## Tech Stack
- Java, Spring Boot, Spring Data JPA / Hibernate
- Thymeleaf, HTML, CSS
- H2 database (MySQL-ready)
- Maven

## Run Locally
1. Clone the repo: `git clone https://github.com/sayednavaf/hospital-appointment.git`
2. Open the `Doctor-Appointment-Scheduler-master` folder
3. Run `./mvnw spring-boot:run`
4. Open http://localhost:8080
